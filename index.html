01Selected work

01 Academic project

Network Intrusion Detection System

A hybrid detector that watches network traffic and flags attacks two ways: known signatures and statistical anomalies. A packet capture layer feeds a deep packet inspector, a signature engine and a machine-learning anomaly model, and a dashboard reports what they find.

It ships with its own attack generator, so detection can be tested against traffic I control instead of guessing.

  • Python
  • scikit-learn
  • Packet capture
  • Anomaly detection

02 In development

Focus Lock

A deliberately minimal Android app. Set an end time and the phone locks down until it passes. Calls, texts and the torch still work, and a music app can be allowed. Social media apps can never be added to the allowed list, and that rule is built in, not a setting.

  • Android
  • Kotlin
  • Jetpack Compose

04About

Background

I am a developer from Taraba State, Nigeria. My work sits in three places: network security tooling, mobile software, and academic research. They are different subjects but the same method — look at a system, find where it fails, and ask what would fix it.

I work on Ubuntu, with the terminal as the main tool. Most of what I build starts as a script, becomes a module, and only then gets an interface.

How I work

  • Correctness first — a feature that is wrong is not a feature.
  • Test against traffic or data I control, not assumptions.
  • Small commits, clear messages, work that can be reviewed.
  • Write the reasoning down; the code is only half of it.

Currently

  • Building Focus Lock in Kotlin and Jetpack Compose.
  • Working on the network intrusion detection system.
  • Writing up research on drug abuse and crime control in Taraba State.
  • Sharpening my React Native and Node.js work.
